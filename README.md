This repo contains the markdown files from which the " ... Additional Notes and Exercises" PDFs are generated.
They are exposed for easier copying of included code by the students as the MSE Moodle site does not offer a suitable rendering possibilities. 

The PDF files on the MSE moodle site remain the definitive versions of the respective files.
